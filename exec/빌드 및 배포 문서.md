# Debate Arena - 빌드 및 배포 가이드

## 개요
이 문서는 Debate Arena 프로젝트의 GitLab 소스 클론 이후 빌드 및 배포를 위한 상세 가이드입니다.

## 1. 사용 기술 및 버전 정보

### 1.1 JVM 및 Java 정보
- **Java Version**: OpenJDK 21
- **JVM 설정**: 
  - Heap 메모리: 최소 2GB 권장
  - Spring Boot 애플리케이션별 포트 할당

### 1.2 웹서버 및 WAS
- **웹서버**: Nginx (리버스 프록시)
  - HTTP/HTTPS 지원
  - SSL/TLS 인증서 자동 갱신 (Let's Encrypt)
- **WAS**: Spring Boot 내장 Tomcat
  - **debate-arena**: 8080 포트 (OAuth2, JWT 인증, 토픽 관리)
  - **matching**: 8081 포트 (WebSocket 기반 매칭)
  - **debate**: 8082 포트 (토론방 관리, STT 처리)
  - **signaling**: 8083 포트 (WebRTC 시그널링)

### 1.3 기술 스택 버전
- **Spring Boot**: 3.5.4
- **Gradle**: 8.14.3
- **MySQL**: 8.0.43
- **Redis**: 8.0.3
- **Node.js**: v22 (Jenkins에서 사용)
- **Vue.js**: 3.5.17
- **TypeScript**: 5.8.3
- **Vite**: 7.0.4
- **Docker**: 컨테이너 기반 배포
- **Docker Compose**: 마이크로서비스 오케스트레이션

### 1.4 AI 서버
- **Python**: 3.11+
- **FastAPI**: 0.116.1
- **uvicorn**: 0.35.0
- **ChromaDB**: 1.0.15 (벡터 데이터베이스)
- **PyTorch**: 2.5.1+cu121 (GPU 지원)

### 1.5 미디어 서버
- **Node.js**: v16.0.0+
- **mediasoup**: 3.16.7 (WebRTC SFU)

### 1.6 IDE 및 개발 도구
- **권장 IDE**: IntelliJ IDEA, VS Code
- **Jenkins**: CI/CD 파이프라인
- **Git**: 소스 코드 관리

## 3. 빌드 및 배포포 명령어

### 3.1 전체 프로젝트 빌드 및 배포

** 1. 인프라 실행 **
```
bash start-infra.sh
```
** 2. AI 서비스 빌드 및 실행 **
- 초기 환경 설정 및 실행
```

```
- 이후 실행
```
# 루트 디렉토리에서 실행
bash (root)/start-ai.sh
```

** 3. 애플리케이션 빌드 및 실행**
```bash
# 루트 디렉토리에서 실행
./start-dev.sh
```

### 3.2 개별 서비스 빌드(참고용)

## 5. 배포 시 특이사항

### 5.1 포트 매핑
- **HTTP**: 80 → Nginx
- **HTTPS**: 443 → Nginx (SSL 인증서 필요)
- **MySQL**: 3306
- **Redis**: 6379
- **MediaSoup UDP**: 40000-40100

### 5.2 SSL/TLS 인증서
- **발급 기관**: Let's Encrypt
- **도메인**: i13a408.p.ssafy.io
- **자동 갱신**: certbot 설정
- **볼륨 마운트**: `/etc/letsencrypt:/etc/letsencrypt:ro`

### 5.3 헬스체크 설정
```yaml
healthcheck:
  test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
  timeout: 20s
  retries: 10
```

### 5.4 리소스 제약사항
- **Hikari Connection Pool**: 최대 5개 연결
- **Redis Lettuce Pool**: 최대 8개 활성 연결
- **WebRTC UDP 포트**: 40000-40100 범위

### 5.5 로그 관리
```bash
# 통합 로그 확인
./show-logs.sh

# 개별 서비스 로그

```

- **JPA/Hibernate**: ORM 매핑

- **Redis Repository**: 캐시 데이터 관리

## 8. 트러블슈팅

### 8.1 일반적인 문제 해결
- **Docker 네트워크 통신 문제**: `host.docker.internal` 사용
- **서비스 간 의존성 문제**: `depends_on` 설정 확인
- **Redis 인증 문제**: 패스워드 설정 확인
- **WebSocket 인증 문제**: JWT 토큰 유효성 검증

### 8.2 포트 충돌 해결
```bash
# 포트 사용 확인
netstat -tlnp | grep :8080

# 기존 컨테이너 정리
docker-compose down
docker system prune -f
```

### 8.3 SSL 인증서 문제
```bash
# 인증서 갱신
sudo certbot renew

# 인증서 확인
sudo certbot certificates
```
