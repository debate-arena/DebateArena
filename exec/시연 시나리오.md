# 시연 시나리오
## 1) 접속 & 로그인

1. 브라우저에서 `http://i13a408.p.ssafy.io/` 접속
2. 헤더에서 **로그인** 클릭 → **Google로 로그인** → 본인 계정 선택
3. **닉네임 설정** 모달에서 닉네임 입력
    - 길이: **2자 이상 16자 이하**
    - **중복 불가**, 입력 완료 시 사용 가능 여부가 즉시 표시됩니다.

> 💡 닉네임은 서비스 내 표시 이름으로 사용됩니다.
> 

---

## 2) 메인 페이지

1. 최상단에 **다음 주제 세트 변경까지 남은 시간** 타이머가 표시됩니다.
    - 타이머 옆 **?** 아이콘에 마우스를 올리면 타이머 설명 툴팁이 보입니다.
2. 타이머 아래에 **현재 주제 세트 중 하나의 주제**가 보입니다.
    - 좌·우 **화살표 버튼**으로 주제를 변경할 수 있고, **30초 후 자동**으로 다음 주제가 표시됩니다.
3. 그 아래에는 **3가지 진영 아이콘**(북극곰, 물범, 펭귄)이 표시됩니다.
4. **북극곰/펭귄**을 클릭하면 해당 아이콘이 커지며 **배경색 + 진영 내용**이 아이콘 위에 나타납니다.
5. *물범(랜덤)**을 클릭하면 **북극곰 또는 펭귄 중 하나**가 무작위로 선택된 것과 동일한 효과가 납니다.
6. **주제가 바뀔 때에도** 랜덤으로 북극곰/펭귄 중 하나가 선택된 효과가 납니다.
7. 메인에서 **“매칭 페이지로” 버튼** 또는 헤더의 **매칭** 메뉴를 통해 **매칭 선택 페이지**로 이동합니다.

> ℹ️ 진영 선택은 매칭에서 사용할 선호 정보를 구성합니다.
> 

---

## 3) 매칭 선택 페이지

1. 페이지 상단: **모드 선택(1:1, 2:2)** · **다음 주제 세트 변경까지 남은 시간** · **게임 시작** 버튼이 있습니다.
2. 모드는 기본적으로 **둘 다 선택됨**이며, 선택된 모드를 다시 누르면 **선택 해제**할 수 있습니다.
3. 타이머는 **다음 주제 세트 변경까지 남은 시간**을 보여줍니다.
4. **게임 시작**을 누르려면 **최소 1개의 모드**와 **최소 1개의 주제에 대한 진영 선택**이 필요합니다.
5. 하단에는 **현재 세트의 주제 카드**들이 표시됩니다.
6. 카드 상단에는 **주제 내용**이 노출됩니다.
7. 카드 하단에는 **[선택1] – [상관없음] – [선택2]** 형태의 버튼 3개가 있으며 **한 가지만 선택**할 수 있습니다.
8. 특정 주제를 **선택하지 않아도 되지만**, **최소 1개 주제**에 대해서는 진영을 선택해야 **게임 시작**이 가능합니다.
9. **게임 시작** 클릭 시 **매칭 대기 페이지**로 이동합니다.

> 💡 상관없음은 매칭 시 균형을 맞추기 위한 자동 배치에 활용됩니다.
> 

---

## 4) 매칭 대기 페이지

1. 페이지 상단에 **아이콘**이 표시됩니다.
2. 그 아래에는 **내가 기다린 시간**을 보여주는 **대기 타이머**가 표시됩니다.
3. 최하단에는 **내가 선택한 주제·진영·모드** 요약 카드가 보입니다.
4. **매칭이 성사되면** 자동으로 **매칭 수락 페이지**로 이동합니다.

---

## 5) 매칭 수락 페이지

1. 화면 중앙에 **원형 진행바**가 표시되며, 이는 **수락 가능 시간**을 의미합니다.
2. 진행바 상단에는 **남은 수락 시간**이 타이머로 표시됩니다.
3. 그 아래에 **매칭된 주제 내용**, 이어서 **내 진영/게임 모드**가 순서대로 표시됩니다.
4. 하단 영역 바로 위에는 **진영별 연결/응답 상태**가 아이콘으로 표시됩니다(수락/거절/대기).
5. 최하단에는 **수락** 버튼과 **거절** 버튼이 있습니다.
6. **거절**하거나 **15초 내 미응답**일 경우 **매칭 선택 페이지**로 돌아갑니다.
7. 내가 **수락**했지만 다른 참가자가 **거절/미응답**이면 **매칭 대기 페이지**로 복귀합니다.
8. **모두 수락**하면 **토론방 페이지**로 이동합니다.

## 6) 토론방 페이지

### (1) 연결 & 준비

1. 입장하면 **RTC 연결 화면**이 표시되며, **모두 연결**되면 **준비 화면**으로 전환됩니다.
2. 준비 화면 상단에 **30초 타이머**, 아래에는 **진영 아이콘 + 사용자 아이디**가 표시됩니다.
    
    **30초가 지나면** 자동으로 **토론 화면**으로 전환됩니다.
    

### (2) 토론 화면 구성

1. 최상단에는 **현재 게임 주제**가 표시됩니다.
2. 그 아래에는 **현재 토론 단계**가 표시됩니다.
    - **의견 주장 → 공격 대상 선정 → 공방 단계 → 최종 투표**
3. 단계 표시 아래에는 **진영별 카드**가 있으며,
    - 카드 상단: **선택 옵션(진영 내용)**
    - 그 아래: **진영 아이콘 + 닉네임**
    - 카드 하단: **발언 시간 표시(누가 말하고 몇 초 남았는지)**

### (3) 단계별 진행

- **의견 주장**: 각 유저가 **1분**씩 자신의 의견을 말합니다. **북극곰 진영부터 시작**합니다.
- 발화가 시작되면 카드 아래에 **카톡 말풍선 형태**로 **발화자 텍스트 + 아이콘 + 닉네임**이 표시됩니다.
    - 최초에는 말풍선에 **“요약 중”** 배지가 표시됩니다.
    - 서버에서 **AI 요약**이 도착하면 배지가 **“요약”**으로 바뀌고, **말풍선 내용이 요약**으로 대체됩니다.
    - 이후 **말풍선을 클릭**하여 **요약/STT 원문**을 자유롭게 **토글**할 수 있습니다.
- 모든 유저가 한 번씩 의견을 마치면 **공격 대상 선택** 단계로 이동합니다.
- **공격 대상 선택(30초)**: 상대 진영의 **요약 말풍선**이 표시되며, **누구를 공격할지 클릭**으로 선택합니다.
    
    선택 시간 동안 **자유롭게 변경**할 수 있으며, 말풍선 아래에 **누가 누구를 선택했는지** 표시됩니다.
    
    시간 종료 시 **공방 단계**로 넘어갑니다.
    
- **공방 단계(30초/30초)**:
    - **공격 30초** → **선택된 상대의 방어 30초** 순서로 진행됩니다.
    - **공격자는 칼(🗡️), 방어자는 방패(🛡️)** 아이콘으로 표시되어 역할을 직관적으로 구분합니다.
    - 이 단계도 발화 시 **STT → AI 요약 수신** 흐름과 **요약/원문 토글**이 동일하게 동작합니다.
- **최종 투표(30초)**:
    - **두 진영 중 하나**를 선택합니다. **한 번 선택하면 변경할 수 없습니다.**
    - 시간 종료 시 **투표 결과**가 표시됩니다.

### (4) 결과 표시

- **한 쪽이 승리(예: 1:3)**: **AI가 각 진영의 주장**을 **종합 요약**하여 보여줍니다.
- **무승부**: **AI 판정**이 표시됩니다.
    - 상단: **승리 진영 표기**(예: *펭귄 승*)
    - 하단: **AI 청중단·판정단 결과**(예: *24:26*)
    - 이어서 **판정 근거**(성향/이유)
    - 마지막으로 **승리팀 → 패배팀 순**으로 **진영별 의견 총 요약**을 제공합니다.
- 화면 **우측 채팅창**에서 참여자 간 자유 채팅이 가능합니다(음성 발화 순서와 무관).

## 7) 참고 사항

- **음성/STT/요약**은 네트워크 상태에 따라 지연될 수 있습니다. 요약이 도착하기 전에는 **원문 표시 + “요약 중” 배지**가 보이다가, 요약 수신 시 자동 교체됩니다.
- **투표**는 첫 클릭 시 즉시 확정됩니다. 신중히 선택해 주세요.
- **거절/시간 초과** 시 매칭은 취소되고 **매칭 선택 페이지**로 돌아갑니다.
