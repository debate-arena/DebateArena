# Role 안에 본인 이름으로 폴더 만들고 그 안에 리드미 만들어서 뭐 했는지 적기

# Branch 종류
- 레포지토리를 역할 별로 파서 진행한다고 해도 최종적으로 gitlab으로 평가를 받기에 각각의 작업들을 마치면 여기에 올려주시면 됩니다.

## master
- 최종적으로 배포 / 평가를 받는 자료들이 올라가는 브랜치
- 팀원들의 경우 merge request를 올리고 승인해야 작업 반영 가능

## develop
- master 브렌치에 올리기 전 전체 파일을 합치고 확인하는 브랜치

## frontend
- 프론트엔드 관련 작업

## backend
- 백엔드 관련 작업

## ai_server
- AI 관련 작업용
