## 1주차 (2025.07.07 ~ 2025.07.11)

### ✅ 주요 작업
- [X] GitHub 이슈/PR 템플릿 구성
  - 이슈 템플릿 추가
  - PR 템플릿 추가
  - 레이블 세분화
- [X] 문서화 작업
  - `docs/` 폴더에 프로젝트 규칙 문서화
    - 코드 컨벤션
    - 커밋 메시지 규칙
    - 브랜치 네이밍 컨벤션
    - 그라운드 룰
- [X] 팀 회고 및 작업 템플릿 작성
  - 주간 단위 회고 및 작업 내역을 위한 템플릿 생성
- [X] 프로젝트 폴더 구조 정비
  - 초기 폴더 구조 설계 및 정리


### 💬 회고
- 잘 된 점
  - 템플릿과 레이블을 초기에 잘 세팅하여 협업의 기반을 마련함
  - 작업 내용을 문서화하고 규칙을 명시함으로써 팀원 간의 혼선을 줄일 수 있게 됨

- 어려웠던 점 및 해결방안
  - GitHub 템플릿 구조 파악에 시간이 다소 소요되었으나 공식 문서와 레퍼런스를 참고하여 해결함

- 다음 주 목표
  - 개발 브랜치에서 초기 기능 구현 시작
  - Notion 혹은 GitHub Wiki를 활용한 회의록 정리 체계 마련
  - 첫 스프린트 계획 수립 및 이슈 단위 업무 분배

## 2주차 (2025.07.14 ~ 2025.07.18)

### ✅ 주요 작업
- [X] 문서화 작업
  - 회의 및 미팅 내용 정리
- [X] 기획
  - 닌텐도 "만져라!" 형식의 실시간 웹게임 기획안 작성
  - 여러 기획안에서 발생할 수 있는 문제를 찾고 대안을 제시
  - 다양한 아이디어 제공


### 💬 회고
- 잘 된 점
  - 약속된 시간에 회의가 잘 진행되었음

- 어려웠던 점 및 해결방안
  - 기획을 이야기 할 때 의견 충돌이 많았음
  - 실습코치, 컨설턴트 등 상급자의 의견을 듣고 결정해보려고 함

- 다음 주 목표
  - 기획안 선정 후 아키텍처 설계
  - 할 일을 정리하고 배분

## 3주차 (2025.07.21 ~ 2025.07.25)

### ✅ 주요 작업
- [X] 페이지 레이아웃 설계
  - Figma를 이용해 각 페이지의 대략적인 모습을 설계
- [X] 아이콘 제작
  - 생성형 AI를 이용해 아이콘을 제작한 후 수정을 거쳐 서비스에 사용될 아이콘을 제작함

### 💬 회고
- 잘 된 점
  - Figma의 기초적인 사용방법을 숙지할 수 있었음
  - 개발기간이 길지 않기 때문에 빠르게 의사결정을 할 수 있었음

- 어려웠던 점 및 해결방안
  - Figma를 처음 사용하다보니 익숙해지는 데 시간이 소요되었음

- 다음 주 목표
  - 자신이 맡은 페이지 기능 구현(WebRTC, STT)
  - 페이지 디자인 구체화

## 4주차 (2025.07.28 ~ 2025.08.01)

### ✅ 주요 작업
- 페이지 레이아웃 구현

  - AI Agent와 협업하면서 원하는 느낌의 디자인을 구현할 수 있었음

- 어려웠던 점 및 해결방안
  - WebRTC 연결 과정이 복잡하기 때문에 이를 이해하는데 어려움이 많았음
  - 시그널링 서버를 맡은 팀원과 긴밀하게 소통하며 이해하려고 노력했음

- 다음 주 목표
  - WebRTC 연결
  - STT 구현
  - 음성 채팅
  - 문자 채팅
  - 토론 진행 구현
