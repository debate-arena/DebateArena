# 🌐 도메인 설정 가이드

## 1. 도메인 옵션 비교

### 🆓 무료 도메인
| 서비스 | 도메인 형태 | 장점 | 단점 |
|--------|-------------|------|------|
| Duck DNS | `yourname.duckdns.org` | 완전 무료, 간단 설정 | 서브도메인만 가능 |
| Freenom | `.tk`, `.ml`, `.ga`, `.cf` | 1년 무료 사용 | 갱신 필요, 신뢰도 낮음 |
| GitHub Pages | `username.github.io` | 무료, 안정적 | GitHub 연동 필요 |

### 💰 유료 도메인
| 업체 | 가격(연) | 특징 |
|------|----------|------|
| 가비아 | 2-3만원 | 국내 업체, 한국어 지원 |
| Namecheap | $10-15 | 해외 업체, 저렴함 |
| Cloudflare | $10 | DNS 서비스 포함 |

## 2. Duck DNS 설정 (무료, 추천)

### 2-1. 가입 및 도메인 생성
```bash
1. https://www.duckdns.org/ 접속
2. Google/GitHub 계정으로 로그인
3. 원하는 도메인명 입력
   - mydebate (운영용)
   - mydebate-dev (개발용)
4. IP 주소 입력
   - 운영 서버 IP: 123.456.789.123
   - 개발 서버 IP: 123.456.789.124
```

### 2-2. 자동 갱신 설정 (서버에서)
```bash
# crontab 설정으로 IP 자동 갱신
echo 'mydebate.duckdns.org' | crontab -e
*/5 * * * * curl "https://www.duckdns.org/update?domains=mydebate&token=YOUR_TOKEN&ip="
```

## 3. 가비아 설정 (유료)

### 3-1. 도메인 구매
```
1. gabia.com 접속
2. 원하는 도메인 검색 (.com, .co.kr 등)
3. 결제 및 구매
```

### 3-2. DNS 관리 설정
```
1. 가비아 마이페이지 → DNS 관리
2. A 레코드 추가
   - 호스트: @ (또는 www)
   - 값: 123.456.789.123 (서버 IP)
   - TTL: 3600
3. 서브도메인 추가
   - 호스트: dev
   - 값: 123.456.789.124 (개발서버 IP)
   - TTL: 3600
```

## 4. Cloudflare 설정 (추천, 무료/유료)

### 4-1. Cloudflare 설정
```
1. cloudflare.com 가입
2. 도메인 추가
3. 네임서버 변경 (도메인 업체에서)
4. DNS 레코드 추가
   - Type: A
   - Name: @
   - IPv4 address: 123.456.789.123
   - Proxy status: Proxied (보안+CDN)
```

### 4-2. SSL/TLS 설정
```
1. SSL/TLS → 개요 → Full (strict)
2. Edge Certificates → Always Use HTTPS: ON
3. 자동 HTTPS 리다이렉트 활성화
```

## 5. 실제 프로젝트 적용

### 5-1. 환경별 도메인
```
운영: mydebate.duckdns.org (또는 mydebate.com)
개발: mydebate-dev.duckdns.org (또는 dev.mydebate.com)
```

### 5-2. 서버 설정 확인
```bash
# 도메인이 서버 IP로 잘 연결되는지 확인
nslookup mydebate.duckdns.org
dig mydebate.duckdns.org

# 웹 서버 접속 테스트
curl http://mydebate.duckdns.org
```

### 5-3. Nginx 설정
```nginx
# /etc/nginx/sites-available/mydebate
server {
    listen 80;
    server_name mydebate.duckdns.org;
    root /var/www/html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 6. HTTPS 설정 (Let's Encrypt)

### 6-1. Certbot 설치
```bash
sudo apt update
sudo apt install certbot python3-certbot-nginx
```

### 6-2. SSL 인증서 발급
```bash
sudo certbot --nginx -d mydebate.duckdns.org
sudo certbot --nginx -d mydebate-dev.duckdns.org
```

### 6-3. 자동 갱신 설정
```bash
sudo crontab -e
0 12 * * * /usr/bin/certbot renew --quiet
```

## 7. 트러블슈팅

### 7-1. DNS 전파 확인
```bash
# 전세계 DNS 전파 상태 확인
https://dnschecker.org/

# 로컬 DNS 캐시 삭제
# Windows
ipconfig /flushdns

# Mac
sudo dscacheutil -flushcache

# Linux
sudo systemctl restart systemd-resolved
```

### 7-2. 일반적인 문제들
```
문제: 도메인 접속이 안됨
해결: DNS 전파 대기 (최대 24시간)

문제: www 붙은 주소가 안됨
해결: CNAME 레코드 추가 (www → @)

문제: HTTPS 접속 안됨
해결: SSL 인증서 설정 확인
```
