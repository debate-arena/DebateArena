# 그라운드 룰 (Ground Rules)

## 프로젝트 운영

### 1. 문서화 중심의 협업
- 모든 중요한 논의는 **Jira, Notion** 등에 기록합니다.
- 개인 회고 및 작업 내역은 **각자 README에 주간 단위로 정리**합니다.

### 2. Git 브랜치 전략 및 규칙
- `main` 브랜치에 **기습적인 push를 금지**하며, 반드시 PR 절차를 거칩니다.
- 브랜치는 `develop/feat/*`, `develop/fix/*` 등으로 명확히 구분합니다.
- PR 시 **커밋 메시지와 코드 컨벤션을 반드시 준수**합니다.

### 3. 정기적인 공유 및 피드백
- 매일 **데일리 스크럼**을 통해 진행상황을 짧게 공유합니다.
- PR은 빠르게 리뷰하고, 리뷰어는 **성실하게 피드백**을 남깁니다.

## 생활 수칙

### 1. 일정과 출결 공유
- 평일에는 **취업 준비 상황이나 출결 관련 이슈를 사전에 공유**합니다.
- 결석이나 지각이 예상될 경우, 팀원들에게 미리 알립니다.

### 2. 공지 응답 및 기본 예절
- 팀 공지에는 **이모지 리액션으로 확인 표시**를 남깁니다.
- 팀 내에서는 **"어?" 금지** — 애매한 반응 대신 명확한 피드백을 지향합니다.

## 팀 마인드셋

### 1. 상호 존중
- 서로의 생각과 작업 방식을 **존중하며 비난보다 제안**을 우선합니다.
- 불편하거나 개선이 필요한 사항은 **직접적으로 말하되 예의를 지킵니다.**

### 2. 소통은 적극적으로, 고민은 함께
- **질문이나 문제 상황은 숨기지 말고 공유**합니다.
- 고민은 혼자 끌어안지 말고 **함께 해결할 수 있는 분위기**를 만듭니다.
