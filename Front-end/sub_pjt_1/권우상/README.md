# 1주차 진행상황
## 아이디어 기획 및 구체화 방법 논의
  총 4가지의 아이디어를 기획하고 그에 대해 이야기를 나눔
### 1)온라인 토론 플랫폼
     오란인에서 찬반이 나뉠 수 있는 주제(ex 깻잎 논쟁, 성악설 vs 성선설)에 관해 방을 만들고 토론 하고 싶은 사람들은 참여
     정해진 규칙에 따라 자신의 주장을 펼치고 상대방에게 질문 및 반박의 과정을 거침
     토론의 승패는 투표로 먼저 결정된 후 만약 무승부라면 ai가 판정
     시청자로 들어와서 시청하며 채팅 가능

### 2)스토리 생성형 게임
     어떤 테마의 스토리에 참여 할지 정하고 방을 생성, 방이 생성되면 초기 스토리가 주어짐
     초기 스토리의 경우 큰 틀을 정해 놓아 스토리의 퀄리티의 저점을 보장
     그 후 선택지가 ai에 의해 생성되고 참여자들이 선택 그에 맞게 스토리가 생성 됨
     총 5~10라운드 정도 진행 참여자는 1~4인 
     승패가 결정 되는 대결 형식 보다는 협동으로 좋은 결과를 내는 형태(ex 보물 찾기)

### 3)미니게임천국 스타일의 웹 게임
     여러 종류의 웹 게임이 라운드마다 돌아가며 진행
     총 20라운드 진행 최종 점수가 높은 사람이 승자
     매 라운드 다른 게임이 진행 됨
     참여인원은 최대 4인 정도 
     게임의 종류는 마우스, 키보드를 이용한 반응 속도형 게임
     AI에게 가장 정답에 가까운 순으로 차등 순위를 매기는 게임

### 4)모의 법정 체험 웹 애플리케이션
      사이트에 미리 생성 할 수 있는 여러 주제가 주어짐
      주제를 선택해서 방 생성 가능
      검사, 변호사로 나뉘어짐 구체적인 형량이 아닌 대략적인 형량 정도만(10년 징영혁, 500만원 벌금 X, 징역형 or 벌금형 O)
      최종적으로는 ai판사(학습을 통해 판례 학습)이 판결을 내림 이 때는 구체적인 형량 제시(10년 징영혁, 500만원 벌금 O, 징역형 or 벌금형 X)
